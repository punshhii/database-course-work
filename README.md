# database-course-work
Курсовая работа по дисциплине "Теоретические основы баз данных" на тему "Реализация базы данных для предметной области "Ветеринарная клиника""

## О проекте
 
Данный репозиторий содержит отчёт по курсовой работе, выполненной в рамках обучения по направлению **«Математика и компьютерные науки»** в Санкт-Петербургском политехническом университете Петра Великого.
 
**Тема проекта:** «Функционирование работы многопрофильной ветеринарной клиники».
 
Цель работы — спроектировать и реализовать реляционную базу данных для ветеринарной клиники: от анализа предметной области до наполненной БД и SQL-запросов с анализом их выполнения.
 
---
 
## Ключевые разделы отчёта
 
1. **Аналитика предметной области**
   - Описание предметной области, цели создания БД
   - 7 сущностей и их атрибуты (клиника, администратор, ветеринар, приём, питомец, владелец, товар)
   - ER-диаграмма (42 атрибута) и схема связи объектов
2. **Проектирование**
   - 12 таблиц с описанием атрибутов, типов данных, ограничений и внешних ключей
   - Лингвистическое и графическое описание схемы БД (на русском и английском)
   - Создание БД в MySQL и заполнение 280 039 записями (Python + Faker)
3. **Программирование**
   - 8 SQL-запросов с формулировкой, реляционной алгеброй, кодом, результатами и анализом через EXPLAIN
   - 3 гистограммы (2D и 3D) по результатам запросов
---
 
## Техническая часть
 
- СУБД: **MySQL** (MySQL Workbench 8.0 CE, MySQL Command Line Client)
- Заполнение БД: **Python** (mysql.connector, библиотека Faker)
- Анализ запросов: **EXPLAIN** и **Visual EXPLAIN**
- Объём данных: 12 таблиц, 280 039 записей
